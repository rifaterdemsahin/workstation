First I added new script, with new features, under ai/ai_linux_usage_utiliser.sh

## Summary of Enhanced Script Features

The enhanced script introduces several new features inspired by tools like Claude Code, focusing on usage tracking, immediate feedback, and improved reliability.

---

### Core Features Added

- **Usage Logging System**
    - Every API call logs to `~/.ai_cli/usage.jsonl`
    - Captures: timestamp, model, tokens, cost, response time, request ID

- **New CLI Commands**
    - `ai burn` &mdash; *(placeholder for burn rate display)*
    - `ai stats` &mdash; *(placeholder for usage statistics)*
    - `ai limits` &mdash; *(placeholder for model limits)*

- **Enhanced API Response Processing**
    - Measures response time for each API call
    - Extracts token usage from OpenRouter response
    - Estimates cost when not provided by API
    - Generates unique request IDs

- **Immediate Usage Feedback**
    - Shows token count and cost after each response  
        *Example:*  
        `📊 Usage: 45 in + 123 out = 168 tokens (~$0.0025) [1250ms]`
    Tokens are usually included in json response, so all we are doing is making it visible in our terminal

- **Cross-Platform Compatibility Fixes**
    - Fixed timestamp issues (macOS vs Linux)
    - Safe arithmetic for large numbers
    - Graceful fallbacks when tools are missing

- **Better Error Handling**
    - Checks for `bc` dependency (for cost calculations)
    - Handles missing utilities gracefully
    - Won't crash on arithmetic overflow
