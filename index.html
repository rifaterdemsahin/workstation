🎯 Project Overview

This workstation project serves as a comprehensive setup and configuration guide for a development environment. It follows a structured self-learning approach, organizing resources, scripts, documentation, and implementations across multiple domains.

Key Features:

  • Automated startup scripts for Windows
  • PowerShell automation tools
  • Docker and Kubernetes configurations
  • AI and machine learning integrations
  • Hardware setup and driver management
  • Multi-monitor configurations
  • Backup and restore utilities

🚀 Startup Scripts

Automated startup scripts located in 6_Symbols/startup/desktopscripts/:

Script Description
launch_chrome_urls.ps1 Launches Chrome with specific profiles and URLs
start_gemini_secondbrain.ps1 Opens terminal and starts Gemini agent
run_updates_admin.ps1 Checks and runs system updates (Winget, Chocolatey)
scan_windows_events.ps1 Scans Windows event logs for issues
start_ollama.ps1 Starts Ollama service with nomic-embed-text model
install_startup_shortcuts.ps1 Installs all startup scripts to Windows Startup folder

🤖 AI & Machine Learning

The project includes AI integrations with tools like Ollama for running local language models. The startup scripts automatically initialize the Ollama service with the nomic-embed-text model for text embeddings and semantic search capabilities.
